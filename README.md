# Calendar 📅

**HTML · CSS · JavaScript**

A browser calendar experiment with month navigation, a generated day grid and visual date states. Earlier layout and reminder experiments are preserved alongside the main page.

[Portfolio](https://github.com/ArushiNaik) · [Browse source](https://github.com/ArushiNaik/Calendar)

## What to explore

- Navigate between months.
- Read date calculations in plain JavaScript.
- Compare layout iterations and reminder pages.

## A guide to the code

- `index.html` — main calendar and rendering logic
- `reminders.html` — reminder experiment
- `leftCalendar.html` — alternate layout

## Run locally

Clone the repository and open `index.html` in a browser. No package installation or backend is required. Alternatively, run `python -m http.server 8000` from the root and visit `http://localhost:8000`.

## Project notes

Start with `index.html`; files with draft names are experiments rather than separate supported applications.
